# Dependencies and asset notices

Task objects are procedural primitives; no task mesh or texture assets are bundled.
Robot URDF, collision meshes and USD assets are supplied by the installed pinned
yam_arena dependency. Its I2RT robot asset notice is reproduced below. Isaac Sim,
Isaac Lab, Arena, Inspect Robots, NumPy, SciPy and PyTorch remain external runtime
dependencies; they are not redistributed in this folder. Exact runtime pins are
recorded in runtime-bindings.json. No external runtime is redistributed.
