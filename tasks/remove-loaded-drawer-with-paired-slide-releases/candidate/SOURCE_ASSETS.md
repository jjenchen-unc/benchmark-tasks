Archived native asset notes, preserved verbatim below. Panda geometry is NOT bundled or imported in this Arena port. Runtime uses the installed SDK YAM assets under their existing notices.

## drawers

All geometry is built from MuJoCo primitives in `benches/drawers.py` (boxes and cylinders). No meshes, textures or third-party
assets are used, so there is nothing to license beyond the repo's robot model (robosuite Panda meshes, MIT, already in the repo).
Web search was not used for this bench; product values below come from memory of the public product pages and are marked
**estimated** unless they are the card's own values. The drawers are a scaled model (the card's 260 x 200 x 70 mm), so slide
lengths and travel are scaled with them.
