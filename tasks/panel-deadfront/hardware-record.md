# LR222-LDD and LRDFC-P20 fit record

For the enclosure and cover, the catalogue owner is Leviton Load Center technical support. A distributor holding both exact parts can supply label photographs and visible dimensions; a bench technician with the paired, unpowered assembly can complete the fit and retention entries. Include this sheet, the model numbers, and Figure 12 of the [manufacturer installation instructions](https://leviton.com/content/dam/leviton/residential/product_documents/product_specification/Outdoor%20Load%20Center%20Installation%20Instructions_ENG.pdf). The published geometry and model assumptions are in the [hardware notes](hardware-fit.md).

| Record while the parts are together | Measurement or photograph |
|---|---|
| Enclosure and cover labels, supplied screw X, state of twist-outs | |
| Plate width × height, sheet and folded-edge thickness (mm) | |
| Clear width and height of each open breaker window; distance between their centres and row pitch (mm) | |
| Guides on both sidewalls with plate removed: height, setback, insertion depth, distance between guides (mm) | |
| Same assembly at initial insertion and bottom flush, with ruler in plane | |
| Screw X head/recess viewed straight-on, two dimensions with scale, bit type fitted by hand; major diameter and length (mm) | |
| Turns from first bite to flush and corresponding axial travel (mm); verify seating by manually removing and reinstalling | |
| Clearance around the service tool and lower screw land with cover seated (mm) | |

For the two removable magnetic grips, mark each magnet's starting position on the coated plate. On a supported bench fixture, pull parallel to the actual sheet and record the load at first detectable slip for each grip. Repeat three times and record the surface condition, grip locations, whether the installed cover can be held during the transfer to the upper guide supports, and photos before and after. Cross-check the screw head against the simulation's tool before using a different bit. Complete the last checks on the same hardware used to take the dimensions.
