# Importance and nearest-task comparison

This task represents maintenance access to a compartment whose side actuator releases a spatially separate rotary door latch. The sequence requires the correct actuator-to-door mapping, a safe door sweep, grasping a loose box behind the door, and stable released placement. Remote actuation, generic cabinet retrieval, two-hand unlatching and hands-free placement are already represented elsewhere; none is claimed new by itself. Manufacturer reference: [Southco rotary-latching system](https://media.southco.com/media/static/documents/brochures/20200717-BR-Rotary-WEB.pdf). The simulator uses disclosed conditional latch limits rather than a product-exact cable/claw model.

The authenticated Robocurve board snapshot contained1497tasks at21:01UTC on2026-11-10. Cabinet/cupboard/locker and broader release searches were followed by full instruction/setup/scoring reads of the nearest records. This is a documented comparison, not an official ownership or importance verdict. A final live-board refresh is required before submission.
